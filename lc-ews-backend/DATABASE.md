## 1. Quick Start

```bash
# Install dependencies
pip install -r requirements.txt   # or: pip install fastapi uvicorn sqlalchemy passlib[bcrypt] python-jose

# Seed the database (creates lc_ews.db + inserts default users/zones/params)
python seed.py

# Start the server
uvicorn main:app --reload --port 8000

# Swagger UI (all endpoints documented)
http://localhost:8000/docs
```

## 2. Database Configuration

File: `database.py`

```python
BASE_DIR     = os.path.dirname(os.path.abspath(__file__))
DB_PATH      = os.path.join(BASE_DIR, "lc_ews.db")
DATABASE_URL = f"sqlite:///{DB_PATH}"

engine = create_engine(DATABASE_URL, connect_args={"check_same_thread": False})
```

- `check_same_thread=False` is SQLite-only. **Remove this arg when switching to Azure.**
- The `Base.metadata.create_all(bind=engine)` call in `main.py` auto-creates all tables on startup if they don't exist.
- A runtime migration also runs on startup to safely add the `preferences` column if it's missing (backwards compat guard).

## 3. Migrating to Azure

### Option A — Azure SQL (SQL Server)

1. Install the driver:
   ```bash
   pip install pyodbc
   ```

2. Replace `DATABASE_URL` in `database.py`:
   ```python
   DATABASE_URL = (
       "mssql+pyodbc://<user>:<password>@<server>.database.windows.net:1433"
       "/<db-name>?driver=ODBC+Driver+18+for+SQL+Server"
       "&Encrypt=yes&TrustServerCertificate=no"
   )
   engine = create_engine(DATABASE_URL)   # remove connect_args
   ```

### Option B — Azure Database for PostgreSQL

1. Install the driver:
   ```bash
   pip install psycopg2-binary
   ```

2. Replace `DATABASE_URL`:
   ```python
   DATABASE_URL = "postgresql://<user>:<password>@<server>.postgres.database.azure.com/<db-name>?sslmode=require"
   engine = create_engine(DATABASE_URL)   # remove connect_args
   ```

### Common steps for both options

- Move secrets to environment variables (do not hardcode passwords):
  ```python
  import os
  DATABASE_URL = os.environ["DATABASE_URL"]
  ```

- The SQLAlchemy models in `models/db_models.py` are **fully compatible** with both SQL Server and PostgreSQL — no model changes needed.

- After switching, run `python seed.py` once against the new database to populate users, zones, and risk parameters.

- The JWT secret key is also hardcoded right now. Move it to an env var too:
  ```python
  # auth_middleware.py and routes/auth.py
  SECRET_KEY = os.environ["JWT_SECRET_KEY"]
  ```

## 6. Authentication System

**Algorithm:** JWT (HS256)  
**Token expiry:** 24 hours  
**Secret key:** `asgus_secret_key_2026` ← **change this before Azure deployment**

### JWT Payload

```json
{
  "user_id": "admin01",
  "role": "admin",
  "email": "admin@gmail.com",
  "exp": 1234567890
}
```

### Role Guards (auth_middleware.py)

| Function | Allowed Roles |
|----------|--------------|
| `get_current_user` | Any authenticated user |
| `require_admin` | `admin` only |
| `require_analyst` | `analyst`, `admin` |
| `require_field_officer` | `field_officer`, `admin` |

### Role Mapping (backend → frontend)

| DB value | Frontend value |
|----------|---------------|
| `field_officer` | `field-officer` |
| `analyst` | `analyst` |
| `admin` | `admin` |

### Login Flow

```
POST /api/auth/login
Body: { "email": "...", "password": "..." }

Response:
{
  "access_token": "<jwt>",
  "token_type": "bearer",
  "role": "admin",           ← mapped frontend role
  "user_id": "admin01",
  "name": "Admin",
  "badge": "ADMN-001"
}
```

All subsequent requests must include:
```
Authorization: Bearer <access_token>
```

## 8. ID Generation

```python
def generate_id(prefix: str) -> str:
    return f"{prefix}_{uuid.uuid4().hex[:8]}"

# Examples:
# generate_id("log")  → "log_3f8a1b2c"
# generate_id("obs")  → "obs_9e4c7d1a"
# generate_id("evt")  → "evt_2b5f8e3d"
```

Seeded records (users, zones) use fixed human-readable IDs (`admin01`, `quetta`, etc.) for consistency across environments.
